<h1 align="center">⚡ Event-Driven Architecture Project</h1>
<h3 align="center">Streaming & Real-Time Data Processing with Kafka, Python & Databricks</h3>

---

🚀 **Project Overview**

This project is an implementation of an **Event-Driven Architecture (EDA)** focusing on real-time data processing and streaming pipelines.

The solution integrates different technologies to simulate a modern data platform capable of handling streaming data, event ingestion, storage, and analytics.

---

🏗️ **Architecture Components**

- 📡 **Apache Kafka**
  - Acts as the **event broker**
  - Handles real-time data streaming between producers and consumers

- 🐍 **Python (Google Colab)**
  - Producer and consumer applications
  - Event generation and data processing

- 🍃 **MongoDB**
  - Used as **historical data storage**
  - Stores processed and raw streaming data

- 📊 **Databricks**
  - Streaming consumption from Kafka
  - Data transformation and processing
  - Dashboard creation for real-time insights

---

⚙️ **Key Features**

- 🔄 Real-time data ingestion using Kafka  
- 📥 Producer application generating events  
- 📤 Consumer applications processing events  
- 🧱 Event-driven microservices architecture  
- 💾 Data persistence in MongoDB  
- ⚡ Stream processing with Databricks  
- 📊 Dashboard with real-time visualizations  

---

📊 **Data Flow**

1. Python Producer generates events (Google Colab)
2. Events are sent to Kafka topics
3. Consumers (Python) process the events
4. Data is stored in MongoDB for historical analysis
5. Databricks consumes streaming data from Kafka
6. Data is transformed and visualized in dashboards
